# Results scrolling and Submit status

Reported URL: `/dsa/problem/ultimate-dsa-016-3sum?version=62b831b6-4c58-438e-9442-a78be83e3469`.

The results tab nested a second `.studio-scroll` inside its scrollable tab body.
The inner element consumed wheel events with `overscroll-behavior: contain`,
while its unrestricted height prevented it from scrolling. The regression test
reproduced an outer scroll position stuck at zero when wheeling over a testcase.
ExecutionPanel now uses the tab body's single scroll container. The region can
also receive keyboard focus and exposes a visible focus outline.

Current local Run counts are shown separately from earlier saved practice
receipts. Historical counts are collapsed under "Earlier saved practice attempt"
and explicitly identified as separate from the current Run. Submit's reason is
visible beside the button and after a successful local Run. The availability
check can be refreshed without executing code or creating a submission. When
certification becomes available, a fresh matching certified-public Run is still
required before Submit unlocks. An availability request error keeps Submit closed
and is described as a check failure, rather than a failed solution.

Read-only production check on 2026-10-17 confirmed that exact 3Sum version's latest
suite `c34f14dd-3de2-4199-bf8f-67d0db67f9fb` remains `needs_review`, with zero
active hidden-Submit certificates. The proposed typed registry and report
orchestration tables are also absent. Passing its three statement examples cannot
legitimately unlock hidden grading. The separate owner must apply the pending
extensions and complete the exact source/contract/fixture/certificate review in
`supabase-handoff.md`. No production database mutation or paid provider call is
part of this UI fix.

Validation: the wheel regression failed before removing the nested container
(`scrollTop` remained zero), then passed with keyboard End navigation. The
workspace/execution/report regression covers 23 cases; two newly added assertions
were corrected and rerun after the other 21 passed. Two additional actual
